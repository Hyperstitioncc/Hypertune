Brainfuck is a programming language with eight commands. They act on a tape of 30,000 byte cells, all zero at the start, and a pointer to one cell:
>  move the pointer one cell right
<  move the pointer one cell left
+  add 1 to the current cell (255 wraps to 0)
-  subtract 1 from the current cell (0 wraps to 255)
.  output the current cell as a character
,  read one input character into the current cell (0 when the input has ended)
[  if the current cell is 0, jump to after the matching ]
]  if the current cell is not 0, jump back to after the matching [
Every other character is ignored.

Solved problems:

Problem: Read a non-empty line of text and output it without its first character.
Write the solution as a Brainfuck program in a single ```brainfuck code block.
Solution:
```brainfuck
 ,,[.,]
```

Write the solution as a Brainfuck program in a single ```brainfuck code block.

```brainfuck

```
